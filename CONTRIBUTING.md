# Contributing

We’d love to have you contribute to AspectNet — whether it’s improving docs, fixing bugs, sharing ideas, or exploring new features. </br>
Your help shapes a cleaner, more powerful developer experience for everyone. </br>

## How to contribute

At SimpleBitware we belive in simplicity. </br>
We are using standard GitHub tooling for colaboration. </br>
No special set up is required to run and test the solution. Just clone the repository and run the solution. </br>
If you need any help feel free to contact us.
